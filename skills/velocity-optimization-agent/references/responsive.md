# Responsive and device quality

The package includes the same verified 207-device descriptor snapshot and profile/probe tools used by Kinesis. Reuse an available Kinesis matrix where compatible; compare versions and project breakpoint inputs. The local copy keeps routine checks available when the design skill is absent.

Use CSS viewport dimensions plus orientation, DPR, input/hover, keyboard, theme, reduced motion and device/network class. Include short-height windows, 320 CSS px reflow, intermediate widths, actual breakpoint neighbors, long content/translation, RTL if supported, zoom/text scaling and safe areas. Browser viewport narrowing is not true browser zoom or native dynamic text evidence.

Declare alignment intent. Check containment, text wrapping, sticky/fixed elements, scrolling, touch targets, focus, modal/menu states, primary actions, decorative interception and computed-style contracts. Do not universally center the page or hide body overflow to conceal required content. Screenshots and working hit targets must corroborate geometry.

Native insets, virtual keyboards, foldable hinge/segments and embedded host UI need their actual platform tools. No finite descriptor catalog covers every physical device. Report the actual profiles, state/browser coverage and physical-device gaps. Route difficult cascade/layout/motion identity work to Kinesis with a scoped defect brief.
